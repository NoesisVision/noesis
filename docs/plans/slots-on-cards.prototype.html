POPUP

Walking the relations

Each one starts at calculate's result: DiscountedOffer, already three levels in (products › discountAmounts) to show depth. All three work: click through, go back, go round the loop through apply.

AColumns CHOSEN · with C's path

One column per step, as in a file browser. The path stays on screen and you can branch from any column.

  • Whole path and the siblings at every step in view
  • Branching off earlier is one click
  • Wide: the popup scrolls sideways after three columns

BDrill-in

One type at a time. A row goes in, the breadcrumb goes back to any step, ⌫ goes up one.

  • Narrow; any depth fits the same popup
  • The breadcrumb doubles as the path
  • Only one level visible; siblings of earlier steps are one hop away

CPath

A dotted path you can type, like code. Type to filter the current level, ↵ or . to go in, ⌫ to go up.

  • Fastest with the keyboard: pro↵dis↵app↵
  • Path reads like code a developer writes
  • Least discoverable with a mouse alone
