Prototype AD

Inbox

Everything the team must react to — alerts, meeting outcomes, upcoming events, notes — until it is promoted, dismissed with a reason, or expires.

Capture

Drop it in the team inbox before it is forgotten. Attach a file — a meeting transcript, for example — to land it as one reviewable item.

Dismiss

The reason stays visible to the team, so nobody wonders whether this was simply dropped.

Defer

It leaves the list now and comes back on its own — no one has to remember it.
